# 🌾 UzhavanHub - Smart Agricultural Platform

A comprehensive agricultural platform designed to bridge the gap between farmers, heavy machinery owners, and skilled agricultural laborers.

## 🚀 Key Features
- **🚜 Farm Machinery Rentals:** Browse and book tractors, tillers, and harvesters with transparent hourly pricing.
- **🌾 Farm Labor Allocation:** Request verified laborers based on specific crop tasks (harvesting, weeding, planting).
- **📲 Instant WhatsApp Notifications:** Direct integration triggering instant booking alerts to administrators.
- **🔐 Protected Admin Dashboard:** Secured admin portal with real-time live booking tracking and approval workflows.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Modern JavaScript (Fetch API & LocalStorage sync)
- **Backend:** Node.js, Express.js
- **Database:** MySQL (`ulavan_hub_db`)
